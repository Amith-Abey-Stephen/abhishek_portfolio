# Pilea Next — Video Editor Agency Site

A Next.js (App Router) port of the `scrap` static prototype: a dark, glassmorphism-style
marketing site for a video-editing agency, pixel-faithful to the original HTML/CSS/JS.

## Getting started

Requires Node.js 26 (see `.nvmrc`).

```bash
npm install
npm run dev     # http://localhost:3000
```

## Scripts

| Command        | What it does                          |
| -------------- | ------------------------------------- |
| `npm run dev`  | Start the dev server with hot reload   |
| `npm run build`| Type-check + production build        |
| `npm run start`| Serve the production build           |

## Project structure

```
app/
  layout.tsx        # <html> shell, fonts, metadata, globals.css import
  globals.css       # Full design system ported from the scrap prototype
  page.tsx          # Page composition + booking-modal state
components/
  Nav.tsx           # Fixed pill nav (condenses to logo on scroll)
  Hero.tsx          # Headline, video showcase, floating Frame.io cards, strips
  Creators.tsx      # Creator marquee + "2 000 vidéos" heading
  Work.tsx          # Portfolio marquee rows + feature columns
  Method.tsx        # 4-step process with browser mockups
  CaseShubham.tsx / CaseFanny.tsx   # Case studies + testimonials
  Reviews.tsx       # Masonry review grid
  LogoWall.tsx      # Client logo wall ("Votre logo ?")
  Booking.tsx / BookingCalendar.tsx # Booking widget (reused in modal)
  Faq.tsx           # Accordion FAQ
  Footer.tsx        # Footer + back-to-top
  BookingModal.tsx  # Booking dialog
hooks/
  useSiteEffects.ts # Scroll progress, reveals, parallax, magnetic buttons,
                    # count-ups, method progress line (port of scrap script.js)
public/
  favicon.svg
```

## Notes

- Images are hotlinked (Unsplash / Picsum / Pravatar), same as the prototype.
  To self-host, download them into `public/` and swap the URLs.
- Fonts load from Google Fonts (Instrument Serif, Mona Sans, Inter Tight, Inter).
- `next-env.d.ts` is auto-generated by Next and intentionally gitignored.
